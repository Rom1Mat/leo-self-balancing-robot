# Léo — Self-Balancing ESP32-S3 Robot (LEGO figurine)

**Léo** is a two-wheeled inverted-pendulum robot that balances on its own, is driven from
your phone (real-time touch joystick over WiFi/WebSocket), animates its two arms, and can
run a short autonomous dance. Brain: an **ESP32-S3**.

![Léo the robot](REPLACE_with_a_photo.jpg)

---

## ✨ Features
- **Self-balancing** on two wheels (500 Hz control loop on a dedicated ESP32 core).
- **Real-time control** from any phone/PC: a web page with a **touch joystick**
  (forward/back + turn), no app to install.
- **Two servo arms**: adjustable positions + preprogrammed gestures (wave, up, down).
- **Autonomous 32 s dance** with trajectory estimation (odometry without encoders).
- **Live tuning** from the browser: every control gain, live angle chart and diagnostics.

## 🧠 How it works (in short)
- An **MPU6050** (gyro + accelerometer) provides the tilt, fused with a complementary filter.
- A **PD-on-acceleration** controller computes the wheel acceleration needed to stay
  upright; an outer **PI speed loop** prevents drift and lets you drive by commanding a
  *speed* rather than a fixed lean angle.
- Motor steps are generated by **DDS** (a phase accumulator in a 40 kHz interrupt): the
  commanded speed is applied instantly, with no ramp or dead time — essential for balance.
- Driving runs over **WebSocket** (latency ~a few ms); settings over HTTP.

## 🔌 Wiring

| Signal | ESP32-S3 pin |
|--------|--------------|
| **Left** motor STEP / DIR | GPIO **2** / GPIO **41** |
| **Right** motor STEP / DIR | GPIO **42** / GPIO **1** |
| **EN** (both drivers, LOW = enabled) | GPIO **14** |
| MPU6050 **SDA / SCL** | GPIO **4** / GPIO **5** |
| **Left / right** arm servo | GPIO **15** / GPIO **16** |
| MPU6050 VCC / GND / AD0 | 3V3 / GND / GND |

**Power:** driver VMOT → 12 V (+ 100 µF per driver). ESP32 and servos at 5 V.
**A common ground is mandatory** between the motor supply, the ESP32 and the MPU.

**DRV8825 microstepping = 1/16** → on each driver: **M0 = GND, M1 = GND, M2 = 3V3**
(check your board's silkscreen; full table in the DRV8825 datasheet).

⚠️ Never plug/unplug a stepper motor while the driver is powered — it can destroy the DRV8825.

## ⚙️ Firmware

### Arduino libraries
- **Adafruit MPU6050** (+ **Adafruit Unified Sensor** as a dependency)
- **WebSockets** by *Markus Sattler (Links2004)*
- Everything else (WiFi, WebServer, timer, LEDC) ships with the ESP32 core.

### Install
1. Install **ESP32** board support in the Arduino IDE (Espressif boards manager).
2. Select your **ESP32-S3** board.
3. Open `self_balancing_robot.ino`.
4. **Set your WiFi** at the top of the file:
   ```cpp
   const char* ssid     = "YOUR_WIFI";
   const char* password = "YOUR_PASSWORD";
   ```
5. Upload. Open the serial monitor (115200) to read the robot's IP address.
6. Open that IP in your phone's browser → remote control + settings.

### Tuning
- Hold the robot by hand for the first runs: the provided gains are **starting points,
  to be refined on your own mechanics**.
- Capture your real **balance angle** with the dedicated button on the page.
- Tune **Kp / Kd (acceleration)**, then the **speed loop (Kp/Ki)**.
- If it vibrates at the balance point: lower the **motor current (DRV8825 Vref)** — it's
  the most common cause of low-speed resonance.

## 📱 Usage
- **Start motors**, then drive with the **joystick** (up = forward, left/right = turn).
- **Release** the joystick → automatic braking and position hold.
- **Arm** buttons: wave / up / down / rest, and the autonomous **dance**.
- Fully touch-based, built for phones (full screen; "Add to Home Screen" for an app-like icon).

## 🛟 Safety
- The robot can fall / roll away: run tests in a clear space.
- Built-in watchdog: if the remote disconnects, motion stops on its own.
